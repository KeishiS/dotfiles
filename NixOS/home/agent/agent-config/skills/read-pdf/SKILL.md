# PDFの読み取り

まずテキストを抽出し、数式や図表など、配置や見た目が意味に影響する箇所をページ画像で
確認します。元のPDFは変更せず、生成物は一時ディレクトリへ置きます。

## 前提

`pdfinfo`、`pdftotext`、`pdftoppm`を使用します。画像から文字を認識する処理（OCR）が
必要な場合は、`ocrmypdf`とTesseractの対象言語データも使用します。
このリポジトリの隔離ホームでは、必要なツールを専用のNix環境で使用します。
英語、日本語、文字の向きの検出用データを含みます。次のようにコマンドを実行します。

```bash
nix develop --no-update-lock-file "path:$(readlink -f "$HOME/.config/agent/pdf-env")" -c pdfinfo document.pdf
```

以下の手順のPDF用コマンドにも、同じ`nix develop`から`-c`までを前置します。
シェル呼び出しごとに環境へ入る必要があります。複数のコマンドをまとめる場合は、
`-c bash -c '…'`の中で実行します。Nix環境の定義がない環境では、既存コマンドの有無と
`tesseract --list-langs`の結果を確認します。不足があれば、必要なツールや言語を報告します。

## 手順

1. 文書情報と調査範囲を確認します。

    ```bash
    pdfinfo document.pdf
    workdir="$(mktemp -d)"
    ```

    作成した一時ディレクトリの絶対パスを記録します。別のシェル呼び出しで作業を続ける場合は、
    `workdir`に同じパスを再設定します。

    ページ数と暗号化の有無を確認します。アクセス制御を回避しません。
    質問の対象ページが分かる場合は、その範囲を優先します。

2. おおよその配置を保持してテキストを抽出し、関連箇所を検索します。

    ```bash
    pdftotext -layout document.pdf "$workdir/document.txt"
    ```

    対象範囲が分かる場合は、`-f 3 -l 5`のように開始・終了ページを指定します。
    段組み、脚注、表では、抽出された順序が読む順序と一致するとは限りません。

3. 抽出結果が空、文字化けしている、または不完全な場合は、対象ページの画像を確認し、
   原因に応じてOCRの方法を選びます。

    | ページの状態 | 指定するオプション |
    | --- | --- |
    | 文字情報がない画像だけのページ | `--skip-text` |
    | 既存のOCRによる認識誤りや欠落 | `--redo-ocr` |
    | 文字情報の破損など、上記で改善しないページ | `--force-ocr` |

    `--skip-text`は文字情報があるページをそのまま残すため、文字化けの修復には使いません。
    `--redo-ocr`は既存の見えないOCR文字情報を置き換えます。
    `--force-ocr`はページ全体を画像化するため、必要なページに絞り、一時コピーだけに使います。

    次は、文字情報がない3〜5ページを日本語と英語で認識する例です。

    ```bash
    ocrmypdf --skip-text --pages 3-5 --output-type pdf -l jpn+eng \
        document.pdf "$workdir/document-ocr.pdf"
    pdftotext -layout -f 3 -l 5 "$workdir/document-ocr.pdf" "$workdir/document-ocr.txt"
    ```

    オプション、ページ範囲、言語は文書に合わせて選びます。`--pages`はOCRの対象範囲であり、
    出力PDFには対象外のページも残ります。OCR由来の文字には認識誤りがあり得るため、回答で明示します。

4. 解釈や引用の根拠となる箇所を、元のPDFのページ画像と照合します。

    ```bash
    pdftoppm -png -r 150 -f 3 -l 3 document.pdf "$workdir/page"
    ```

    細かな記号が読めない場合は解像度を上げます。次の要素を確認します。

    - 数式と数学記号
    - 図とキャプション
    - 表と列の対応
    - 段組みの読み順、脚注、注釈
    - 正確な引用や重要な結論の根拠となる箇所

5. 確認した内容に基づいて回答します。文書に明記された主張と、自分の解釈や推論を
   区別します。重要な主張と引用にはページ番号を付け、印刷上の番号とPDF内のページ位置が
   異なる場合は、どちらを使ったか明示します。

## 信頼性に関する規則

- 抽出結果だけから、欠落した記号や表のセルを推測しません。
- ページ画像を確認せず、OCR出力を正確な引用として提示しません。
- 引用は必要な箇所に限って短く使用し、それ以外は忠実に要約します。
- 読み取れなかったページや節を明記します。
- 継続作業に必要な場合を除き、完了後に自分で作成した一時ディレクトリを削除します。
